# Proyecto semana 1 - Veterinaria Modelado de Entidades

## Dominio

El sistema modela una clínica veterinaria donde se gestionan:

- Pacientes animales
- Dueños de mascotas
- Estado médico
- Vacunas aplicadas

## Entidades

AnimalPatient → representa una mascota atendida  
Owner → representa al dueño del animal

## Tipos utilizados

Status → estado del paciente (active, treatment, discharged)  
Vaccine → tipos de vacunas permitidas

## Funciones

createAnimalPatient → crear paciente  
listPatients → listar pacientes  
filterByStatus → filtrar pacientes por estado

## Tecnologías

TypeScript con tipado estricto
